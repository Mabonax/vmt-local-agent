# Creative templates
Use colour, typography and layout skills to understand the brief. Write a reviewed JSON input for template_plan: template (poster, social, business_card, certificate), title, optional subtitle, footer, primary, accent, background (HEX), and optional asset index 0–3 (not for certificates).
The worker returns a scene and advisory quality report. Do not invent asset paths or factual content. Resolve any text overflow by editing the scene or shortening content with user permission. Use scene_check with the saved scene to review bounding boxes, approximate contrast and text fit. A pass is not visual certification. Use svg_compose with the saved scene and explicitly approved local asset paths in index order. Keep source JSON and SVG. Render PNG/PDF and request actual visual review.
